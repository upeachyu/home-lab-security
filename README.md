# home-lab-security
KVM home lab for pentest: Ubuntu Server, Kali Linux, network isolatiom, port forwarding iptables, fail2ban

#home lab for pentest & blue team practice
#  Домашняя лаборатория для кибербезопасности (Home_Lab)

#  О проекте
Это моя личная лаборатория для практики в области информационной безопасности. 
Она позволяет безопасно тренировать навыки атакующего (Red Team) и защитника (Blue Team), не рискуя домашней или рабочей сетью.
Вся лаборатория развернута на моем ноутбуке с помощью технологии виртуализации.

#  Что использовалось (Стек)
-   Хост-система (основная ОС): Ubuntu 26.04 LTS
-   Виртуализация: KVM + QEMU (менеджер `virt-manager`)
-   Атакующая машина : Kali Linux
-   Целевая машина : Ubuntu Server 26.04 

#  Архитектура и безопасность
-   Обе виртуальные машины находятся в изолированной сети (NAT), чтобы случайно не навредить реальным устройствам.
-   Настроен проброс портов через `iptables`, чтобы с основного ноутбука (хоста) можно было подключаться к учебному серверу по SSH через порт `2222`.

#  Реализованные проекты

# 1. Настройка безопасного SSH (Hardening)
-   Полностью отключен вход по паролю. Теперь зайти на сервер можно только с помощью криптографического ключа (Ed25519).
-   Запрещен прямой вход под пользователем `root` (администратором).
-   Настроен сервис Fail2ban: он автоматически банит IP-адреса, которые пытаются подобрать пароль к серверу.

# 2. Скрипт-анализатор логов на Python
-   Написал скрипт на Python, который читает системные логи (`auth.log`).
-   Скрипт ищет неудачные попытки входа, собирает IP-адреса хулиганов и выводит статистику: кто и сколько раз пытался взломать сервер.

# 3. Автоматизация правил сети (Bash + Systemd)
-   Правила проброса портов (`iptables`) слетают при перезагрузке.
-   Чтобы этого избежать, я написал Bash-скрипт и создал собственный Systemd-сервис. Теперь правила применяются автоматически при каждом включении ноутбука.

#    Чему я научился в ходе работы

-   Понимать, как работает файрвол `iptables` и проброс портов.
-   Автоматизировать рутину с помощью Bash и Systemd.
-   Писать скрипты на Python для базового анализа логов безопасности.
