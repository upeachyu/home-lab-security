# home-lab-security
KVM home lab for pentest: Ubuntu Server, Kali Linux, network isolatiom, port forwarding iptables, fail2ban

#home lab for pentest & blue team practice
# Домашняя лаборатория для кибербезопасности (Home Lab)

## О проекте

Это моя личная лаборатория для практики в области информационной безопасности. Она позволяет безопасно тренировать навыки атакующего (Red Team) и защитника (Blue Team), не рискуя домашней или рабочей сетью.

Вся лаборатория развернута на ноутбуке с помощью технологии виртуализации.

## Стек технологий

* **Основная система:** Ubuntu 26.04 LTS
* **Виртуализация:** KVM + QEMU (менеджер virt-manager)
* **Атакующая машина:** Kali Linux
* **Целевая машина:** Ubuntu Server 26.04 LTS

## Архитектура и безопасность

* Обе виртуальные машины находятся в изолированной сети (NAT), чтобы не навредить реальным устройствам.
* Настроен проброс портов через iptables для подключения с основного ноутбука (хоста) к учебному серверу по SSH через порт 2222.

## Реализованные проекты

### 1. Настройка безопасного SSH (Hardening)

* Полностью отключен вход по паролю. Доступ возможен только с помощью криптографического ключа (Ed25519).
* Запрещен прямой вход под пользователем root (администратором).
* Настроен сервис Fail2ban для автоматической блокировки IP-адресов, которые пытаются подобрать пароль.

### 2. Скрипт-анализатор логов на Python

* Написан скрипт на Python, который читает системные логи (auth.log).
* Скрипт ищет неудачные попытки входа, собирает IP-адреса атакующих и выводит статистику: с какого адреса и сколько раз пытались взломать сервер.

### 3. Автоматизация правил сети (Bash + Systemd)

* Правила проброса портов (iptables) сбрасываются при перезагрузке.
* Для решения этой проблемы написан Bash-скрипт и создан собственный Systemd-сервис. Теперь правила применяются автоматически при каждом включении системы.

## Чему я научился в ходе работы

* Настраивать сеть между виртуальными машинами (NAT, маршрутизация).
* Работать с файрволом iptables и пробросом портов.
* Автоматизировать рутину с помощью Bash и Systemd.
* Писать скрипты на Python для базового анализа логов безопасности.
